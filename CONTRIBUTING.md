# Contributing Guidelines

Thank you for contributing to the Pair Extraordinaire Lab!

## Pull Request Checklist
1. Branch off `main`.
2. Follow Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`).
3. If paired with another developer or AI assistant, include:
   ```git
   Co-authored-by: Full Name <user@users.noreply.github.com>
   ```
4. Open PR against `main` with a clear explanation of changes.
