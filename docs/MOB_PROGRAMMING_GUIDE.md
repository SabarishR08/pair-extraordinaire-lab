# Mob & Ensemble Programming Guide

## What is Mob Programming?
Mob programming (also called ensemble programming) extends pair programming to an entire team working on a single problem simultaneously.

## Multi-Co-Author Git Attribution
When three or more engineers contribute to a single commit, git trailers can be stacked:

```git
refactor: streamline authentication pipeline

Co-authored-by: Alice Developer <alice@example.com>
Co-authored-by: Bob Security <bob@example.com>
Co-authored-by: Charlie Testing <charlie@example.com>
```

GitHub displays all attributed co-authors in commit headers and release digests.
